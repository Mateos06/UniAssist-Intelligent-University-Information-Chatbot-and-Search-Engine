# UniAssist: Metropolitan University of Tirana NLP Project

This is an **educational, source-attributed English corpus and Week 1–3 NLP laboratory** for a proposed university information search engine and chatbot. It is **not** an official UMT service and does not provide binding academic advice.

## Start here

1. Open the `corpus/` directory: 20 UTF-8 plain-text files, **200–300 whitespace-delimited words each**, created as original summaries of public UMT material.
2. Open `metadata.json`: each document's title, genre, measured word count, language of the source, official source URLs and time-sensitivity warning.
3. Open `PROJECT_PROPOSAL.md`: scope, detailed source plan, processing pipeline, evaluation and later milestones.
4. Run the validation script and the three notebooks. The notebooks contain live code and instructions, **not fabricated experimental results**.

## Installation (Windows / VS Code / Jupyter)

Install Python 3.10 or newer. Extract the ZIP, open a terminal in **`UniAssist_UMT`**, and run:

```powershell
python scripts/validate_corpus.py
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m spacy download en_core_web_sm
python -m notebook
```

Open the notebooks in this order and choose **Run All**:

1. `notebooks/01_corpus_overview.ipynb`
2. `notebooks/02_tokenization_sentences.ipynb`
3. `notebooks/03_stemming_lemmatization_wordnet.ipynb`

The notebooks download their required NLTK resources automatically. To regenerate the notebooks if you edit `scripts/build_notebooks.py`, run `python scripts/build_notebooks.py`.

For Linux or macOS, activate the environment using `source .venv/bin/activate`. For Google Colab, upload the project files while **preserving the folder structure** or mount Google Drive, install the dependencies in a cell, and set the working directory to the project root. The source corpus itself needs no downloaded model.

## Source and safety policy

- The **only institutional source domain** in this version is `umt.edu.al`; URLs are documented in `metadata.json` and deduplicated in `sources.json`.
- The text is **independently paraphrased for teaching**; it is not a reproduction of university documents. Source rights and ownership remain with their publishers.
- Some official pages concern admission requirements, fees and Erasmus eligibility. These may change. **Do not quote a corpus summary as a current rule** without checking the current source.
- The academic calendar source is a **2026–2027 Albanian PDF**; the corpus deliberately does not state unverified exact dates.
- The examination regulation is accessible on a **2022 path** and is summarized with a historical-source warning; current applicability has **not** been established.
- The corpus mixes **information articles, visitor FAQs and policy-document summaries**. The user requested three text types, but the lecturer must confirm whether mixed genres satisfy the assignment.
- Each original text is 200–300 words by `str.split()` count. This simple counting convention can differ from NLTK/spaCy token counts.
- No generated text is presented as an actual student enquiry or officially published UMT statement.

## Suggested report format

1. Purpose and research questions.
2. Source selection, metadata and ethical constraints.
3. Corpus inventory: 20 English files, genres, total words, per-document lengths.
4. Week 1, 2, 3 tables **generated by the notebooks** plus screenshots or short output samples.
5. Error analysis: limitations of tokenizers, stemmers, lemmas and WordNet on UMT vocabulary.
6. Next steps: a source-linked TF–IDF/BM25 search baseline, autocomplete, grounded FAQ assistant, evaluation queries and interface.

## Future build, not part of Week 1–3
